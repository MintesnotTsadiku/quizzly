# GatherPlay visual and listening starters

These original SVG illustrations and synthesized sine-tone WAV files were created for GatherPlay. They ship with the application under its MIT license; no external media service is required.

- umbrella, bicycle, key: object identification clues with equivalent descriptive alt text.
- memory: one red square, two yellow circles and two green triangles. Visible during study and reveal, hidden during recall.
- caption: a chair holding a kite, for creative caption prompts.
- ascending, descending, steady: three equal-length synthesized notes, for identifying pitch direction. The interface offers replay and an optional visual pattern.

These are live game clues, separate from the existing illustrated how-to artwork. Existing artwork has not been deleted.
